Calcolo Imposta Contribuente - Console Application

Descrizione:
Questo progetto è una console application in C# che permette di inserire i dati di un contribuente e calcolare l'imposta sul reddito annuale secondo scaglioni definiti.
Il programma guida l’utente passo passo nell’inserimento delle informazioni e restituisce un riepilogo completo del contribuente, mostrando l’imposta da versare.

Funzionalità:
Inserimento dei dati del contribuente tramite console:
-Nome e Cognome
-Data di nascita
-Codice fiscale
-Sesso
-Comune di residenza
-Reddito annuale

Calcolo dell’imposta basato sugli scaglioni di reddito:
-Reddito ≤ 15.000 → aliquota 23%
-15.001 – 28.000 → aliquota 27%
-28.001 – 55.000 → aliquota 38%
-55.001 – 75.000 → aliquota 41%
-Oltre 75.000 → aliquota 43%

Visualizzazione di un riepilogo completo del contribuente con imposta calcolata.

Tecnologie:
-C#
-Object-Oriented Programming (OOP)
-.NET Console Application
